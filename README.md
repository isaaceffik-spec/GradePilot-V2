# Gradepilot

A React + Vite student performance platform for IB, SAT, ACT, and DUAL.

## Features
- Username-only persistence with generated 4-word identity
- Local storage for IB courses, GPA, SAT/ACT scores, and DUAL stats
- IB 2-step course selection and dashboard
- SAT/ACT prediction graphs with benchmark comparisons
- Test center recommendations by commute, reliability, environment, and stress
- DUAL competitive mode with friend requests, category reveal, and Elo tracking

## Run locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start development server:
   ```bash
   npm run dev
   ```

## Notes
- This app is built to run entirely in the browser with local persistence.
- No passwords, signup, or login are used.
- If `npm` is not available in your environment, install Node.js first.
